    第 0 關　為什麼要 DP

    同一個小問題一再出現，就把答案記下來。

    記什麼？dp[…] 代表什麼
    怎麼來？看「最後一步」
    從哪開始？最小情況的答案
    誰先算？依賴的格子先有答案
    答案在哪？最後一格或全表最大

    第 1 關　一維遞推

    一個陣列，由小算到大。

    狀態
    dp[i] 走到第 i 階的方法數
    轉移
    dp[i] = dp[i-1] + dp[i-2]
    初始
    dp[0] = dp[1] = 1
    答案
    dp[n]
    Python 模板

    基本版

    # 爬樓梯：每次走 1 階或 2 階，走到第 n 階有幾種走法
n = int(input())                    # 讀入階數 n
dp = [0] * (n + 2)                  # dp[i] = 走到第 i 階的方法數，多開兩格避免 n 很小時出界
dp[0] = 1                           # 站在地面算 1 種
dp[1] = 1                           # 走到第 1 階只有 1 種
for i in range(2, n + 1):           # 由小到大，保證 dp[i-1]、dp[i-2] 已經算好
    dp[i] = dp[i - 1] + dp[i - 2]   # 最後一步是走 1 階或走 2 階
print(dp[n])                        # 答案在 dp[n]

    只留兩個變數

    a, b = 1, 1                  # a 代表 dp[i-2]，b 代表 dp[i-1]
for i in range(2, n + 1):    # 往後推到第 n 階
    a, b = b, a + b          # 新的 b 是舊 a + 舊 b，新的 a 是舊 b
print(b)                     # b 就是 dp[n]
    常見的坑
    • n 很小時，陣列要多開幾格避免出界
    • 多筆查詢：先一次建表
    • 看清楚範圍與是否要取模

    練習題

      第 2 關　加一個狀態維度

      一個編號不夠用，就多記一項資訊。例：長度 n 的 0/1 字串，不能有連續兩個 1。

      狀態
      dp[i][s] 結尾是 s 的個數
      轉移
      dp[i][0] = dp[i-1][0] + dp[i-1][1]
      dp[i][1] = dp[i-1][0]
      答案
      dp[n][0] + dp[n][1]
      Python 模板
      # 長度 n 的 0/1 字串，不能有連續兩個 1，共有幾種？
n = int(input())            # 讀入長度 n
end0 = 1                    # 長度 1 且結尾是 0 的字串數（"0"）
end1 = 1                    # 長度 1 且結尾是 1 的字串數（"1"）
for i in range(2, n + 1):   # 一格一格往後長
    new0 = end0 + end1      # 結尾放 0：前面結尾是什麼都可以
    new1 = end0             # 結尾放 1：前面一定要是 0
    end0 = new0             # 更新兩個狀態
    end1 = new1
print(end0 + end1)          # 兩種結尾的總和就是答案
      常見的坑
      • 更新時用舊值算新值，先存到暫存變數再覆蓋
      • 答案很大就邊算邊取模

      練習題

        第 3 關　「以第 i 個結尾」

        dp[i] = 一定要以第 i 個結尾的最佳值；答案取全部的最大，不一定是最後一格。

        最大連續區間和（Kadane）

        最長遞增子序列（LIS）

        Kadane 轉移
        dp[i] = max(dp[i-1], 0) + a[i]
        LIS 轉移
        dp[i] = max(dp[j]) + 1，j<i 且 a[j]<a[i]
        答案
        max(dp)
        Python 模板

        Kadane

        n = int(input())                      # 讀入數字個數
a = list(map(int, input().split()))   # 讀入 n 個數字
best = a[0]                           # 目前最大的連續和，答案可能是負數，所以不能從 0 開始
cur = a[0]                            # cur 代表「以目前這格結尾」的最大連續和
for i in range(1, n):                 # 從第二個數字開始
    if cur > 0:                       # 前面累積的和是正的，接上去有幫助
        cur = cur + a[i]
    else:                             # 前面是 0 或負的，不如從這格重新開始
        cur = a[i]
    if cur > best:                    # 答案是所有「結尾」中最大的
        best = cur
print(best)                           # 輸出最大連續和

        LIS（O(n²)）

        n = len(a)                      # a 是已經讀好的數列
dp = [1] * n                    # 每個數字自己就是長度 1 的遞增子序列
for i in range(n):              # 依序決定每個結尾
    for j in range(i):          # 看前面每個 j
        if a[j] < a[i]:         # a[i] 可以接在 a[j] 後面
            if dp[j] + 1 > dp[i]:
                dp[i] = dp[j] + 1
print(max(dp))                  # 答案是所有結尾中最長的
        常見的坑
        • 答案可能是負數，初始值別設 0
        • 答案取 max(dp)，不是 dp[n-1]
        • 嚴格遞增的二分搜用 bisect_left

          第 4 關　背包與錢幣

          金額（容量）當狀態；內層迴圈的方向，決定每個物品能用幾次。

          ① 湊零錢：貪心 vs DP

          ② 迴圈方向：同一個物品（重 3、值 4），容量 9

          最少個數
          dp[j] = min(dp[j], dp[j-c] + 1)
          方法數
          dp[j] += dp[j-c]，面額放外層
          0/1 背包
          dp[j] = max(dp[j], dp[j-w] + v)
          內層方向
          無限：由小到大；0/1：由大到小
          Python 模板

          無限背包：最少硬幣數

          INF = 10 ** 9                           # 代表「湊不出來」的很大數字
dp = [INF] * (c + 1)                    # dp[j] = 湊出金額 j 最少需要幾個硬幣
dp[0] = 0                               # 湊 0 元需要 0 個硬幣
for coin in coins:                      # 一種面額一種面額處理
    for j in range(coin, c + 1):        # 由小到大：允許同一種硬幣重複使用
        if dp[j - coin] + 1 < dp[j]:    # 用一個 coin 比目前更少
            dp[j] = dp[j - coin] + 1
print(dp[c])                            # 若仍是 INF 代表無解

          無限背包：方法數

          dp = [0] * (c + 1)                  # dp[j] = 湊出金額 j 的組合數
dp[0] = 1                           # 湊 0 元有 1 種（什麼都不拿）
for coin in coins:                  # 面額放在外層：每種組合只會被數到一次（不計順序）
    for j in range(coin, c + 1):    # 由小到大：可重複使用
        dp[j] = dp[j] + dp[j - coin]

          0/1 背包：最大價值

          W = 100                                  # 背包容量
dp = [0] * (W + 1)                       # dp[j] = 容量 j 以內的最大價值，全部先設 0
for w, v in items:                       # items 是 (重量, 價值) 的清單，一個物品處理一次
    for j in range(W, w - 1, -1):        # 由大到小：確保同一個物品不會被用兩次
        if dp[j - w] + v > dp[j]:        # 放進這個物品比較划算
            dp[j] = dp[j - w] + v
print(dp[W])

          0/1 背包：能不能湊出（位元表）

          dp = 1                      # 用一個大整數當位元表：第 k 個位元是 1 代表「長度 k 湊得出來」
for m in ms:                # 每根金屬棒最多用一次
    dp = dp | (dp << m)     # 原本能湊出的長度，加上 m 之後也能湊出
if (dp >> n) & 1:           # 檢查第 n 個位元是不是 1
    print("YES")
else:
    print("NO")
          常見的坑
          • 0/1 背包內層改成由小到大，就變成無限背包
          • 最少個數的 dp 要先設成很大的數，不是 0
          • 面額沒有規律時，貪心可能是錯的

            第 5 關　二維網格

            兩個座標，每一格由「上面」或「左邊」推來。

            狀態
            dp[i][j] 走到 (i, j) 的最小路徑和
            轉移
            min(dp[i-1][j], dp[i][j-1]) + g[i][j]
            答案
            dp[n-1][m-1]
            Python 模板
            n, m = map(int, input().split())                      # 讀入列數 n、行數 m
g = [list(map(int, input().split())) for _ in range(n)]   # 讀入整張地圖
INF = 10 ** 9                                         # 很大的數字，代表「不存在的來源」
dp = [[INF] * m for _ in range(n)]                    # dp[i][j] = 走到 (i, j) 的最小路徑和
for i in range(n):                                    # 由上到下
    for j in range(m):                                # 由左到右
        if i == 0 and j == 0:
            dp[i][j] = g[i][j]                        # 起點本身
        else:
            best = INF                                # 先假設兩個來源都不存在
            if i > 0 and dp[i - 1][j] < best:        # 從上面來
                best = dp[i - 1][j]
            if j > 0 and dp[i][j - 1] < best:        # 從左邊來
                best = dp[i][j - 1]
            dp[i][j] = best + g[i][j]                 # 加上這一格的數字
print(dp[n - 1][m - 1])                               # 終點的答案
            常見的坑
            • 第一列、第一行沒有上面或左邊，要先判斷
            • 最大路徑和：缺席的來源設成負無限大
            • 多組測資要重置 dp

              第 6 關　雙序列：LCS 與編輯距離

              兩個前綴長度當座標，比較最後一個字。可以改字串自己試。

              LCS 相同
              dp[i-1][j-1] + 1
              LCS 不同
              max(dp[i-1][j], dp[i][j-1])
              編輯距離 不同
              min(上, 左, 左上) + 1
              編輯距離 初始
              dp[i][0] = i，dp[0][j] = j
              Python 模板（LCS）
              s = input()                                 # 讀入第一個字串
t = input()                                 # 讀入第二個字串
n = len(s)                                  # s 的長度
m = len(t)                                  # t 的長度
dp = [[0] * (m + 1) for _ in range(n + 1)]  # 多開一列一行代表「空字串」，初始值剛好都是 0
for i in range(1, n + 1):                   # s 取前 i 個字
    for j in range(1, m + 1):               # t 取前 j 個字
        if s[i - 1] == t[j - 1]:            # 最後一個字相同（字串索引要減 1）
            dp[i][j] = dp[i - 1][j - 1] + 1
        else:                               # 不同：取「去掉 s 最後字」或「去掉 t 最後字」的較大者
            if dp[i - 1][j] > dp[i][j - 1]:
                dp[i][j] = dp[i - 1][j]
            else:
                dp[i][j] = dp[i][j - 1]
print(dp[n][m])                             # 答案在右下角
              常見的坑
              • dp 的 i 是「前 i 個字」，字串索引是 s[i-1]
              • LCS 是子序列，不是連續的子字串

                  第 8 關　區間 DP

                  狀態是一段區間，轉移是在中間切一刀。例：矩陣連乘，求最少乘法次數。

                  狀態
                  dp[i][j] 第 i 到 j 個矩陣的最少次數
                  轉移
                  min( dp[i][k] + dp[k+1][j] + 合併花費 )
                  順序
                  區間長度由短到長
                  Python 模板
                  # dims 長度 n+1：第 i 個矩陣的大小是 dims[i] x dims[i+1]
n = len(dims) - 1                         # 矩陣個數
BIG = 10 ** 18                            # 很大的數字
dp = [[0] * n for _ in range(n)]          # dp[i][j] = 乘起第 i 到 j 個矩陣的最少乘法次數，i==j 時為 0
for L in range(1, n):                     # 區間長度由小到大（很重要！）
    for i in range(0, n - L):             # 區間左端點
        j = i + L                         # 區間右端點
        dp[i][j] = BIG                    # 先設成很大，再找最小
        for k in range(i, j):             # 在 k 與 k+1 之間切一刀
            cost = dp[i][k] + dp[k + 1][j] + dims[i] * dims[k + 1] * dims[j + 1]
            if cost < dp[i][j]:           # 這個切法更便宜
                dp[i][j] = cost
print(dp[0][n - 1])                       # 整段區間的答案
                  常見的坑
                  • 一定要先枚舉區間長度，否則會用到還沒算的格子
                  • 合併花費要看題目，不一定和矩陣相同

                    第 9 關　進階

                    狀態可以是集合、位數、節點、兩個位置。先玩玩看「用整數表示集合」。

                    狀態壓縮：用一個整數表示「誰被選了」

                    數位 DP一位一位決定，沿著 N 的每一位累加。
                    樹上 DP先算子節點，再合併給父節點。
                    雙路徑兩個人同步走相同步數，用步數 + 兩個位置當狀態。
                    單調佇列優化取前面一段範圍的最大值，O(nk) 降到 O(n)。
                    Python 模板（分組問題）
                    # 2N 個人兩兩分組，使距離總和最小。dis[i][j] 是第 i 人與第 j 人的距離
size = 1 << n                             # 所有集合共 2^n 個
INF = float("inf")                       # 無限大
dp = [INF] * size                        # dp[S] = 集合 S 內的人都已分好組的最小距離和
dp[0] = 0                                # 一個人都沒分組時，距離和是 0
for S in range(size):                    # 由小的集合推到大的集合
    if dp[S] < INF:                      # 這個集合有被走到
        i = 0                            # 找第一個還沒分組的人
        while i < n and (S >> i) & 1:
            i = i + 1
        for j in range(i + 1, n):        # 跟後面還沒分組的人配對
            if (S >> j) & 1 == 0:
                T = S | (1 << i) | (1 << j)    # 把 i、j 都加進集合
                if dp[S] + dis[i][j] < dp[T]:
                    dp[T] = dp[S] + dis[i][j]
print(dp[size - 1])                      # 所有人都分好組的答案
                    常見的坑
                    • 狀態壓縮 n 約 20 以內，否則 2ⁿ 會爆
                    • 數位 DP 別重複算「位數比 N 少」的情況
